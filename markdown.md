
# Password Strength Checker

## Project Description
A Python Flask web application that evaluates password
characteristics and provides suggestions for improvement.

## Features
- Password strength classification
- Uppercase and lowercase checks
- Number and special character checks
- Password length validation
- Password visibility toggle
- Responsive interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation
1. Install Python 3.
2. Create and activate a virtual environment.
3. Install the requirements:
   pip install -r requirements.txt
4. Start the application:
   python app.py
5. Open http://127.0.0.1:5000 in your browser.

## Privacy
The demo does not store passwords. Passwords entered
are submitted to the local Flask application for checking.
Do not use real account passwords for testing.

## Disclaimer
This is an educational project. Its strength labels are
based on simple rules, not a complete security assessment.
